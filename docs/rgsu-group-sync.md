# Обновление групп РГСУ

## Причина сбоя отметки успеха

Проверка сервера 22 сентября 2026 года показала:

- Cron запускал проверку групп ежедневно в 03:20 UTC (06:20 МСК).
- 19–22 сентября процесс cron завершался в 03:50 UTC: срабатывал `curl --max-time 1800`.
- Сервер продолжал работу после отключения клиента. В журнале приложения есть завершение обновления 1212 из 1212 групп.
- Скрипт не получал успешный ответ и не обновлял `groups-last-success`. Последняя отметка осталась от 31 августа.
- Stderr curl не попадал в `logger`. Cron отбрасывал его с сообщением `No MTA installed, discarding output`.

## Новый процесс

Cron запускает `scripts/update-rgsu-groups.ts` напрямую через Node.js 22 и `tsx`.
Общий внешний `flock` из crontab сохраняется до завершения процесса.
Лимит выполнения — шесть часов. Код выхода при таймауте или ошибке не обновляет отметку успеха.
Stdout и stderr попадают в journal с тегом `akademiks-rgsu-groups`.

Алгоритм:

1. Повторить отправку сохранённых Telegram-уведомлений.
2. Обновить GUID известных групп через точное совпадение названия.
3. Запросить расписания всех известных преподавателей на текущую и три следующие недели по московскому времени.
4. Получить названия групп из поля `teacherName`: РГСУ возвращает строку или массив.
5. Проверить новые названия через поиск групп РГСУ и точное совпадение. Проверить конфликты внутренних ID и GUID.
6. Добавить подтверждённые группы. Затем проверить базовые названия известных подгрупп и добавить недостающие варианты.
7. Отправить Telegram-уведомления о сохранённых группах с указанием источника.
8. Сохранить отчёт. Обновить отметку успеха, если нет ошибок запросов, БД или Telegram.

Ответ «Не удалось найти GUID преподавателя» и отсутствие точного совпадения группы попадают в предупреждения.
Сетевые сбои, блокировка РГСУ и ошибки сохранения не считаются успешной проверкой.
Группы, преподаватели, занятия и связи пользователей при этой проверке не удаляются.

Поиск ограничен преподавателями из нашей базы и четырьмя неделями. Он не гарантирует обнаружение всех групп университета.

## Локальный запуск только для добавления

Параметр `--add-only` пропускает обновление GUID существующих групп.
Он сохраняет поиск через преподавателей, поиск вариантов групп и Telegram-уведомления.
CLI запрашивает до трёх расписаний одновременно. Общий лимит остаётся один запрос в секунду.

```sh
node --env-file=.env --import tsx scripts/update-rgsu-groups.ts --add-only --output /tmp/rgsu-groups-additions.json
```

Для доступа к рабочей базе используйте отдельное окружение и SSH-туннель.
Не заменяйте локальный `.env` настройками рабочей базы.

## Telegram

Используется существующая настройка Telegram РГСУ:
`RGSU_PROXY_ROTATION_TELEGRAM_BOT_TOKEN` и `RGSU_PROXY_ROTATION_TELEGRAM_CHAT_ID`.

Очередь записывается до INSERT группы. Перед отправкой проверяется наличие сохранённой группы.
Неотправленные сообщения остаются для следующего запуска. Большой список разбивается на сообщения.
При сбое между отправкой Telegram и сохранением подтверждения возможен повтор сообщения.

## Состояние

Каталог: `${XDG_STATE_HOME:-$HOME/.local/state}/akademiks-rgsu`.

- `groups-last-success`: время последнего полного успешного запуска.
- `groups-last-report.json`: результат последнего завершённого обхода.
- `groups-pending-notifications.json`: очередь Telegram.
- `groups-update.lock`: блокировка одновременного запуска через CLI и HTTP.

Не запускайте CLI в обход общего `flock`, когда работает парсер расписания.
Перед применением к рабочей базе сохраните резервную копию.

## Проверка без записи в базу

Из каталога проекта с Node.js 22:

```sh
node --env-file=.env --import tsx scripts/update-rgsu-groups.ts --dry-run --output /tmp/rgsu-groups-preview.json
```

Предпросмотр возвращает будущие добавления в `addedGroups`. Он не обновляет группы и не отправляет уведомления об их добавлении.

## Проверки изменений

```sh
node --env-file=.env --import tsx --test src/lib/utils/schedule/rgsu/group-sync.test.ts src/lib/utils/schedule/rgsu/errors.test.ts src/lib/utils/schedule/rgsu/request-throttle.test.ts scripts/run-rgsu-groups-cron.test.ts
bash -n scripts/run-rgsu-groups-cron.sh
```

Живой тест 22 сентября охватил 12 преподавателей и обнаружил 218 уникальных названий.
По снимку рабочей базы отсутствовали пять названий. Поиск РГСУ подтвердил четыре:

| Группа | GUID |
| --- | --- |
| ЛЕЧ-С-1-Д-2026-28 | 18135 |
| ЛЕЧ-С-1-Д-2026-29 | 18136 |
| ЛЕЧ-С-1-Д-2026-30 | 18137 |
| СКД-Б-03-Д-2025-1 | 18714 |

`ИНБ-Б-02-Д-2025-2` не подтвердилась в поиске. Один преподаватель не найден по GUID.
Этот тест не изменял базу и не отправлял Telegram. Полный обход всех преподавателей не выполнялся.
