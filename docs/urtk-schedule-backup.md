# Бэкап расписания УРТК в Google Таблицы

Каждые 12 часов скрипт выгружает расписание УРТК из базы в Google-таблицы папки бэкапа.
Формат совпадает с таблицами колледжа «Расписание занятий»: на каждую группу две колонки — «Дисциплина» и «Ауд.», под ними строка преподавателя.

## Файлы

- Группы раскладываются по файлам по префиксу названия: «Ис-231» попадает в «Ис», «Рм-112» — в «Рм».
- «Преподаватели» — одна таблица со всеми преподавателями. Вместо преподавателя под дисциплиной указана группа.
  Поток из нескольких групп записывается одним занятием: «Би-131, Би-132, Э-172».
- Подгруппы и разные занятия в одной паре разделяются пустой строкой, преподаватели или группы — переводом строки.
- Каждая неделя — отдельный лист. Выгружается текущая неделя и все следующие, где есть занятия.
  В воскресенье текущей считается следующая неделя.
  Если впереди занятий нет, выгружается последняя неделя с занятиями.
- Столбцы есть у всех групп и преподавателей из базы, даже без занятий на неделе.

Таблица с тем же названием перезаписывается, ссылки на неё не меняются.
Прошлые выгрузки доступны в истории версий Google Таблиц: «Файл» → «История версий».
Файлы, которых нет в выгрузке, скрипт не трогает.

## Настройка

1. Откройте доступ к папке сервисному аккаунту `GOOGLE_API_EMAIL` с ролью «Редактор».
   На проде это `app-917@stom-coach.iam.gserviceaccount.com`.
   Таблицы принадлежат сервисному аккаунту и занимают его квоту 15 ГБ.
2. Укажите в `.env` ID папки из её адреса `https://drive.google.com/drive/folders/<ID>`:

```sh
GOOGLE_BACKUP_FOLDER_ID="<ID>"
```

3. Проверьте запуск вручную из каталога проекта:

```sh
scripts/run-urtk-schedule-backup-cron.sh; journalctl -t akademiks-urtk-backup -n 20
```

4. Добавьте задание в crontab пользователя приложения:

```cron
0 */12 * * * /home/vladislav/akademiks/scripts/run-urtk-schedule-backup-cron.sh
```

Журнал пишется в journal с тегом `akademiks-urtk-backup`. Лимит выполнения — один час.
При ошибке хотя бы одного файла скрипт завершается с кодом 1, остальные файлы выгружаются.
